Archive Console Cookies

Companion for Archive Console: polls while a yt-dlp batch run needs fresh cookies, exports YouTube + Google cookies, and PUTs cookies.txt via the Console API.

Helps when yt-dlp reports The page needs to be reloaded (or other session challenges). Reloads first, waits for load, then exports cookies.

Default reloads only the tab used for cookie export — less disruptive.

Match Settings → port in Archive Console (state.json).

Default ~10s (0.167 min). Use a value ≤ Console cookie poll (e.g. 15s).

Leave blank: auto-export uses an open YouTube tab (Watch Later → active → Subscriptions → any) — same as popup Site + container. Only set this if you use Firefox Multi-Account Containers and YouTube is not in the default store.
