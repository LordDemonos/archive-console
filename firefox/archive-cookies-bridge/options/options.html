Archive cookies bridge

Polls Archive Console while a yt-dlp batch run is paused on cookie/auth errors, exports YouTube + Google cookies, and PUTs cookies.txt via the Console API.

Match Settings → port in Archive Console (state.json).

Default ~10s (0.167 min). Use a value ≤ Console cookie poll (e.g. 15s).

Leave blank: auto-export uses an open YouTube tab (prefers Subscriptions) — same as popup Site + container. Only set this if you use Firefox Multi-Account Containers and YouTube is not in the default store.
