What you already have

          
This app listens on 127.0.0.1 only. Your archive root (see Settings) holds batch inputs and config files. Cookies are never read from your browser — export Netscape-format files yourself: cookies.txt at the root for yt-dlp, and cookies/<site>.txt for gallery-dl (see Cookies below).

Cookies

          
yt-dlp (Watch Later, channels, videos) reads cookies.txt at the archive root, or use --cookies-from-browser in yt-dlp.conf for YouTube-only work. gallery-dl (Galleries) uses cookies/<extractor>.txt — auto-wired when present; see Supported sites for names. Reddit user feeds: prefer OAuth in gallery-dl.conf.

          
Official export guidance: FAQ — How do I pass cookies to yt-dlp? Extensions cited there include Get cookies.txt LOCALLY (Chrome) and the cookies.txt Firefox add-on. This UI never reads your browser jar — you export and drop files yourself.

Troubleshooting

          

            PATH / “not found”
            
If Verify reports missing tools, add their install directory to your user PATH or set explicit paths in Settings where available. Restart the console after environment changes.

          

          

            HTTP 428 — cookie confirm
            
Manual YouTube batch starts may require acknowledging cookies.txt (or disable the gate in Settings). Dry-run skips the gate.

          

          

            Reddit / block pages
            
Refresh cookies and try again; some extractors need logged-in sessions. See upstream FAQ and extractor notes.

          

          

            Empty gallery preview
            
Confirm gallery-dl works from a shell, URL is supported, and cookies/config match the site.

          

          

            Gifsky — no videos / huge GIFs
            
Scan finds .m4v and .mp4 under your galleries output root — enable Galleries → Video fallback if Reddit clips are missing. HQ presets make large GIFs; try Compact or Balanced in gifsky.conf. Leftover *_frame*.png from older runs can be deleted manually; new runs clean temp frames automatically.

            Configure ExifTool under Settings → General and DeepL under Settings → DeepL. Apply uses Path.rename on the server (computed names), not ExifTool for writing.

          Settings
          
          
          Runtime, backups, schedule records, and cookie reminders. Schedules only run while the server process stays up (use the tray launcher or a Windows service — not a closed CMD window).
          
        
          

        
          
          
          General & runtime
          
          
          Binds to 127.0.0.1 only (not LAN). Changing the port or archive root requires restarting the console process.
          
          
          
          Usually the repo you start with start_archive_console.bat (e.g. ). Also set via ARCHIVE_CONSOLE_ROOT env before first launch if state.json is empty.
          
          
          
            Accessible folders are set automatically from Download output folders (below), plus logs/ and cookies/. Each output root includes all subfolders.

          Storage & retention
          
          
          Manual cleanup only—nothing deletes on server start. Eligible paths must sit under the archive root and download output folders. Run folders use directory mtime; operator ZIPs use file mtime. logs/latest_run*.txt targets are always kept (even if older than retention). A job must not be running. cookies.txt, yt-dlp.conf, and console state.json are never deleted. History may reference removed folders—the report link can 404 until you run again. Editor .bak files live under archive_console/backups (outside the archive tree) and are not pruned here.
          
          
          Not affiliated with yt-dlp.
          
          
          
          
          
          
          
            
            
            
          
          
          
          
          
          
        
          

        
          
          
          Headless / tray (Windows)
          
          
          Use start_archive_console_tray.bat (repo root) or python tray_app.py from archive_console with venv + pystray. This calls the same uvicorn argv as CLI (app.server_cli.uvicorn_argv). If the port is already serving /api/health, the tray attaches and Exit closes only the tray. Otherwise it spawns the server and Exit stops it (blocks if a job is running unless you confirm). See ARCHIVE_CONSOLE.md.
          
        
          

        
          
          
          Operator backups (ZIP)
          
          
          Creates archive_console_backup_*.zip under a path you choose (under the archive root, e.g. logs/…). Includes optional copies of console state.json and logs/. Does not read cookies.txt unless you include it manually (not recommended in shared backups).
          
          
          
          
          
          
          
          
          
            
            
          
          
          
          
          
          
        
          

        
          
          
          Automatic scheduling
          
          
          
          
          
          When enabled, saved schedules run at their set times on this PC (local timezone). Restart Archive Console after changing this toggle. Configure watch later / channels / videos times on YouTube batch. Configure gallery-dl saved-source crawls on Gallery batch → Saved sources. Missed minutes while the PC sleeps are not replayed.
          
          
          
          
        
          

        
          
          
          Notifications (Gotify)
          
          
          Push to a Gotify server on your network when batch jobs start or finish: YouTube (watch_later, channels, videos) and gallery-dl (galleries). Scheduled saved-source gallery crawls send one batch start and one summary (not per URL). Messages use Markdown with run stats; failures include cookie/auth hints when detected in the log. Application token is stored in state.json (operator backups may include it).
          
          
          
          
          Use the application token from Gotify → Apps (the app you created for Archive Console). That is not the server URL above, and not a client token from the Android app. Paste the token and click Save; leaving the token field empty keeps the previously saved token.

Use Input lists → cookies.txt after you export from the browser yourself.
          
          
          
          
          
          
          
          
          
          
            
            
            
            
          
          
          
          
        
          

        
          
          
          Danger zone
          
          
          Stop Archive Console server — releases the port on 127.0.0.1. Tray spawn mode: the tray exits when the server process stops (watchdog). Attach mode (tray connected to an already-running server): only the server stops — close the tray from its menu if you want the icon gone. Restart from your launcher or terminal.
